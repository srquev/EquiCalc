How does SIP compounding work?

Each contribution enters at a different time. Earlier contributions have longer to compound, while later contributions have less time. We project one month at a time using a constant assumed return.

Monthly rate = (1 + annual return ÷ 100)^(1 ÷ 12) − 1
Beginning of month: next value = (current value + SIP) × (1 + monthly rate)
End of month: next value = current value × (1 + monthly rate) + SIP

What does a SIP step-up change?

A 10% annual increase takes a 10,000 monthly SIP to 11,000 in year 2 and 12,100 in year 3. The percentage changes your contribution, not your investment return. Increases start after each completed interval; a maximum SIP caps every subsequent contribution.

How does the goal planner work?

We search for a starting monthly SIP by repeatedly running the same monthly projection. The search uses at most 60 bound-expansion steps and 100 refinement steps, targeting a corpus within one paisa or a small numerical tolerance for very large values. A cap that makes the target unreachable produces an explanation instead of an invalid result.

Projections use the unrounded solution. The displayed monthly SIP is rounded to two decimals, so entering that displayed amount again may produce a slightly different corpus.

How are inflation and a delayed start handled?

Today’s purchasing-power equivalent = estimated final value ÷ (1 + inflation ÷ 100)^(total months ÷ 12). This is an illustration, not an exact purchasing-power forecast.

For a delayed start, both the lump sum and monthly SIP begin later and keep the same overall end date. The step-up schedule starts with the first delayed contribution. Money held before that date is not assigned a return.

Are any of these outcomes guaranteed?

No. Constant returns are a modelling assumption. Markets vary, and this projection excludes fees, taxes and inflation unless an inflation-adjusted figure is explicitly shown. More contributions change the result; the calculator does not recommend one approach over another.
